About this release

This is the first public release of the article catalog: the publisher table of contents (TOC) for the core 49 economics journals, 2010–2025. The TOC is the article list. Every item in an issue is kept. Research articles are marked Research article; front matter, editorials, comments, replies, and similar items are marked Other; conference papers are marked Proceedings. The catalog shows research articles first, and the filter shows the rest.

Author names are shown as recorded, with their source. As printed in the TOC means the names come from the publisher’s TOC. OpenAlex (name only) means the TOC had no names and the names come from OpenAlex names recorded by the collector. OpenAlex by DOI (name only) means neither the TOC nor that record had names, so the names come from the OpenAlex work for the item’s DOI. Crossref by DOI (name only) means the names come from the Crossref record for the DOI. From the official article page means the names were read from the journal’s own article page. All are names only, not linked identities. When neither source has names, none are shown. Names are not merged, cleaned, or completed. For TOC bylines stored as “A, B, and C” followed by each name, the printed byline is shown. In an issue list, each name is a link labeled “Search for this name.” It searches the catalog for that name string. The same display name is not one person, and there is no author page.

Not in this release: a person registry, author identifiers, affiliations, author pages, and any working files from the collection process. Affiliation panels and unique-author pages are planned for later releases. DOIs link to doi.org. When a TOC record has no DOI, the catalog says so. A DOI pasted into search opens the catalog item when that DOI is already in this release. A DOI that is not in the release is reported as missing. The site does not fetch or invent a record.

The compiled catalog, site code, and documentation are licensed under CC-BY-4.0. Article titles, author bylines, and publisher tables of contents remain the publishers’.

Built 2026-11-14 (Asia/Hong_Kong) from releases/articles_toc_2010_2025/ with python scripts/build_site.py. Journal-level tables are under downloads (journals.csv, issues.csv, coverage.csv, authors_missing_by_journal_year.csv, summary.json). The repository is kochiuyu/econ-journal-authors. Searching all journals uses data/search/, a title-and-author index built from the same freeze, not the raw article table. DOI lookup uses data/search/doi.json, a location map from the same freeze. Each journal has a page on Journals, with the counts, years, and issues in this freeze. A year or an issue on that page opens the catalog.
